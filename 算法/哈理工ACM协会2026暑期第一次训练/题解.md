## A 题：行列式求值

### 题目描述

给定一个 $n$ 阶行列式 $A$，求 $|A|$ 在模 $p$ 意义下的值。

**数据范围**：$1 \leq n \leq 600$，$1 \leq a_{i,j} < 10^9 + 7$，$1 \leq p \leq 10^9 + 7$

### 算法思路

使用 **高斯消元法** 求行列式：
1. 通过初等行变换将矩阵化为上三角矩阵
2. 行列式的值 = 主对角线元素的乘积
3. 每次行交换会使行列式变号

**关键点**：
- 模意义下需要使用 **逆元** 进行消元
- 使用 **扩展欧几里得算法** 求逆元（支持 $p$ 不是质数的情况）
- 如果主元与 $p$ 不互质（逆元不存在），行列式为 0

### 代码实现

```cpp
// 扩展欧几里得算法求逆元
int exgcd(int a, int b, int &x, int &y)
{
    if (b == 0)
    {
        x = 1;
        y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return d;
}

// 求 a 在模 p 下的逆元
int inv(int a)
{
    int x, y;
    int d = exgcd(a, p, x, y);
    if (d != 1) return -1; // 不存在逆元
    return ((x % p) + p) % p;
}

// 高斯消元求行列式
int determinant(vector<vector<int>> &a, int n)
{
    int det = 1;

    for (int i = 0; i < n; i++)
    {
        // 找到第 i 列非零元素
        int pivot = -1;
        for (int j = i; j < n; j++)
        {
            if (a[j][i] != 0)
            {
                if (pivot == -1 || a[j][i] > a[pivot][i])
                {
                    pivot = j;
                }
            }
        }

        if (pivot == -1) return 0;

        // 交换行
        if (pivot != i)
        {
            swap(a[i], a[pivot]);
            det = (p - det) % p;
        }

        // 累乘对角线元素
        det = det * a[i][i] % p;

        // 计算逆元并消元
        int pivot_inv = inv(a[i][i]);
        if (pivot_inv == -1) return 0;

        for (int j = i + 1; j < n; j++)
        {
            if (a[j][i] == 0) continue;
            int factor = a[j][i] * pivot_inv % p;
            for (int k = i; k < n; k++)
            {
                a[j][k] = ((a[j][k] - factor * a[i][k]) % p + p) % p;
            }
        }
    }

    return (det % p + p) % p;
}
```

**时间复杂度**：$O(n^3)$

## B 题：矩阵快速幂

### 题目描述

给定 $n \times n$ 的矩阵 $A$，求 $A^k$，结果对 $10^9 + 7$ 取模。

**数据范围**：$1 \leq n \leq 100$，$0 \leq k \leq 10^{12}$，$|A_{i,j}| \leq 1000$

### 算法思路

类似于整数快速幂，使用 **矩阵快速幂**：
- 将 $k$ 二进制拆分
- 递归计算 $A^{2^i}$
- 时间复杂度从 $O(n^3 \cdot k)$ 降到 $O(n^3 \log k)$

### 代码实现

```cpp
const int MOD = 1e9 + 7;

struct Matrix
{
    int n;
    vector<vector<int>> a;

    Matrix(int size) : n(size)
    {
        a.assign(n, vector<int>(n, 0));
    }

    Matrix operator*(const Matrix &other) const
    {
        Matrix res(n);
        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < n; j++)
            {
                for (int k = 0; k < n; k++)
                {
                    res.a[i][j] = (res.a[i][j] + a[i][k] * other.a[k][j]) % MOD;
                }
            }
        }
        return res;
    }

    static Matrix identity(int size)
    {
        Matrix res(size);
        for (int i = 0; i < size; i++)
        {
            res.a[i][i] = 1;
        }
        return res;
    }
};

Matrix matrix_pow(Matrix base, int k)
{
    Matrix res = Matrix::identity(base.n);

    while (k > 0)
    {
        if (k & 1)
        {
            res = res * base;
        }
        base = base * base;
        k >>= 1;
    }

    return res;
}
```

**时间复杂度**：$O(n^3 \log k)$

## C 题：矩阵乘法与模拟（线性同余法）

### 题目描述

使用线性同余法生成随机数：$X_{n+1} = (aX_n + c) \bmod m$

给定 $m, a, c, X_0, n, g$，求 $X_n \bmod g$。

**数据范围**：$n, m, a, c, X_0 \leq 10^{18}$，$1 \leq g \leq 10^8$

### 算法思路

由于 $n$ 可能达到 $10^{18}$，不能直接递推。将递推关系写成矩阵形式：

$$
\begin{bmatrix} X_{n+1} \\ 1 \end{bmatrix} = \begin{bmatrix} a & c \\ 0 & 1 \end{bmatrix} \begin{bmatrix} X_n \\ 1 \end{bmatrix}
$$

因此：

$$
\begin{bmatrix} X_n \\ 1 \end{bmatrix} = \begin{bmatrix} a & c \\ 0 & 1 \end{bmatrix}^n \begin{bmatrix} X_0 \\ 1 \end{bmatrix}
$$

使用矩阵快速幂在 $O(\log n)$ 时间内求解。

**关键点**：⚠️ **防止溢出！**

由于 $m \leq 10^{18}$，两个模数后的数相乘会达到 $10^{36}$，**爆 long long**！

解决办法：使用 `__int128` 做中间乘法。

### 代码实现

```cpp
struct Matrix
{
    int a[2][2];
    int mod;

    Matrix(int m = 1) : mod(m)
    {
        a[0][0] = a[0][1] = a[1][0] = a[1][1] = 0;
    }

    // 矩阵乘法
    // 注意：m 最大 1e18，两数相乘会爆 long long，必须用 __int128 中转
    Matrix operator*(const Matrix &other) const
    {
        Matrix res(mod);
        for (int i = 0; i < 2; i++)
        {
            for (int j = 0; j < 2; j++)
            {
                __int128 sum = 0;
                for (int k = 0; k < 2; k++)
                {
                    sum += (__int128)a[i][k] * other.a[k][j] % mod;
                }
                res.a[i][j] = (int)(sum % mod);
            }
        }
        return res;
    }
};

signed main()
{
    IOS;

    int m, a, c, x0, n, g;
    cin >> m >> a >> c >> x0 >> n >> g;

    Matrix trans(m);
    trans.a[0][0] = a % m;
    trans.a[0][1] = c % m;
    trans.a[1][0] = 0;
    trans.a[1][1] = 1;

    Matrix result = matrix_pow(trans, n);

    // 同样要用 __int128 防止溢出
    int xn = (int)(((__int128)result.a[0][0] * (x0 % m) + result.a[0][1]) % m);

    cout << xn % g << endl;

    return 0;
}
```

**时间复杂度**：$O(\log n)$

## D 题：组合数问题

### 题目描述

给定 $n, m, k$，求有多少对 $(i, j)$ 满足：
- $0 \leq i \leq n$
- $0 \leq j \leq \min(i, m)$
- $k \mid \binom{i}{j}$（$k$ 整除 $\binom{i}{j}$）

**数据范围**：$0 \leq n, m \leq 2 \times 10^3$，$1 \leq t \leq 10^4$

### 算法思路

**核心思想**：预处理 + 二维前缀和优化

1. **预处理组合数**：使用杨辉三角递推，模 $k$ 计算
   $$\binom{i}{j} = \binom{i-1}{j} + \binom{i-1}{j-1}$$

2. **一维前缀和**：`sum[i][j]` 表示第 $i$ 行中，$[0, j]$ 列有多少个满足 $k \mid \binom{i}{y}$ 且 $y \leq i$ 的

3. **二维前缀和**：`f[i][j]` 表示前 $i$ 行的累加答案
   $$f[i][j] = f[i-1][j] + \text{sum}[i][\min(i, j)]$$

4. **查询**：$O(1)$ 返回 `f[n][m]`

### 代码实现

```cpp
const int N = 2010;

int C[N][N];    // C[i][j] 表示组合数 C(i, j) % k
int sum[N][N];  // sum[i][j] 表示第 i 行中，[0, j] 列有多少个满足 k|C(i,y) 且 y<=i 的
int f[N][N];    // f[i][j] 表示 (x,y) 满足 0<=x<=i, 0<=y<=min(x,j) 且 k|C(x,y) 的对数
int k;

void init()
{
    // 杨辉三角递推组合数（模 k）
    for (int i = 0; i < N; i++)
    {
        for (int j = 0; j <= i; j++)
        {
            if (j == 0)
            {
                C[i][j] = 1 % k;
            }
            else
            {
                C[i][j] = (C[i - 1][j] + C[i - 1][j - 1]) % k;
            }
        }
    }

    // 预处理一维前缀和 sum[i][j]
    for (int i = 0; i < N; i++)
    {
        sum[i][0] = (C[i][0] == 0) ? 1 : 0;
        for (int j = 1; j < N; j++)
        {
            sum[i][j] = sum[i][j - 1];
            if (j <= i && C[i][j] == 0)
            {
                sum[i][j]++;
            }
        }
    }

    // 预处理二维前缀和 f[i][j]
    for (int i = 0; i < N; i++)
    {
        for (int j = 0; j < N; j++)
        {
            f[i][j] = (i > 0) ? f[i - 1][j] : 0;
            int max_y = min((long long)i, (long long)j);
            f[i][j] += sum[i][max_y];
        }
    }
}

signed main()
{
    IOS;

    int t;
    cin >> t >> k;

    init();

    while (t--)
    {
        int n, m;
        cin >> n >> m;

        cout << f[n][m] << endl;
    }

    return 0;
}
```

**时间复杂度**：
- 预处理：$O(N^2) = O(2010^2) \approx 400$ 万
- 每次查询：$O(1)$
- 总复杂度：$O(N^2 + t)$

**优化要点**：
- 初始版本每次查询 $O(n)$，会 TLE
- 必须用二维前缀和做到 $O(1)$ 查询

## E 题：并查集

### 题目描述

实现并查集的合并和查询操作。

**数据范围**：$1 \leq N \leq 2 \times 10^5$，$1 \leq M \leq 10^6$

### 算法思路

并查集模板题，使用两个优化：
1. **路径压缩**：查找时将路径上所有节点直接连到根节点
2. **按秩合并**：合并时将秩小的树连到秩大的树下

时间复杂度接近 $O(M \alpha(N))$，其中 $\alpha$ 是阿克曼函数的反函数，可以认为是常数。

### 代码实现

```cpp
const int N = 2e5 + 10;

int fa[N];  // fa[i] 表示 i 的父节点
int rnk[N]; // rnk[i] 表示以 i 为根的树的秩

// 初始化
void init(int n)
{
    for (int i = 1; i <= n; i++)
    {
        fa[i] = i;
        rnk[i] = 0;
    }
}

// 查找根节点（带路径压缩）
int find(int x)
{
    if (fa[x] != x)
    {
        fa[x] = find(fa[x]); // 路径压缩
    }
    return fa[x];
}

// 合并两个集合（按秩合并）
void unite(int x, int y)
{
    int fx = find(x);
    int fy = find(y);

    if (fx == fy) return;

    // 按秩合并
    if (rnk[fx] < rnk[fy])
    {
        fa[fx] = fy;
    }
    else if (rnk[fx] > rnk[fy])
    {
        fa[fy] = fx;
    }
    else
    {
        fa[fy] = fx;
        rnk[fx]++;
    }
}

// 判断是否在同一集合
bool same(int x, int y)
{
    return find(x) == find(y);
}
```

**时间复杂度**：$O(M \alpha(N)) \approx O(M)$

## 🎯 核心知识点总结

### 1. 矩阵快速幂

**适用场景**：
- 线性递推优化（如斐波那契数列）
- 图论中的路径计数
- DP 转移矩阵优化

**模板**：
- 矩阵乘法：$O(n^3)$
- 快速幂：二进制拆分，$O(n^3 \log k)$

### 2. 大数乘法防溢出

当模数接近 $10^{18}$ 时：
```cpp
// 错误：会爆 long long
res = (a * b) % mod;

// 正确：用 __int128 中转
res = (int)((__int128)a * b % mod);
```

### 3. 组合数计算

**杨辉三角递推**：
- 适用于小范围组合数（$n \leq 5000$）
- 递推公式：$\binom{n}{m} = \binom{n-1}{m} + \binom{n-1}{m-1}$
- 可以模任意数，不要求模数是质数

### 4. 前缀和优化

**二维前缀和**：
- 用于快速查询矩形区域和
- 预处理 $O(n^2)$，查询 $O(1)$
- 注意边界处理（如本题的 $j \leq i$ 约束）

### 5. 并查集

**必备优化**：
- 路径压缩：查找时压缩路径
- 按秩合并：合并时控制树的深度
- 两者结合，复杂度接近 $O(\alpha(n))$

## 💡 做题心得

1. **A 题**：模意义下的行列式需要注意逆元的存在性，当 $\gcd(a, p) \neq 1$ 时行列式为 0

2. **C 题**：数据范围 $10^{18}$ 是关键提示，必须防止乘法溢出，使用 `__int128`

3. **D 题**：从 $O(n)$ 查询优化到 $O(1)$ 查询是 AC 的关键，需要仔细设计前缀和

4. **通用技巧**：
   - 看到 $k \leq 10^{12}$，想到快速幂
   - 看到 $t \leq 10^4$、$n \leq 2000$，预处理是关键
   - 看到模数 $10^{18}$，立刻想到溢出问题
