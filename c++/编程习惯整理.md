## 代码模板结构

### 标准模板框架

你的代码通常遵循以下结构：

```cpp
// 头文件引入
#include <iostream>
#include <algorithm>
// ... 其他头文件

using namespace std;

// 宏定义
#define IOS ios::sync_with_stdio(0), cin.tie(0), cout.tie(0)
#define int long long
#define endl '\n'
typedef pair<int, int> PII;

// 常量定义
const int INF = 0x3f3f3f3f;
const int MOD = 1e9 + 7;

// 工具函数（快速幂、gcd、lcm 等）

// 主函数
signed main()
{
    IOS;
    
    // 解题代码
    
    return 0;
}
```

## 头文件引入习惯

### 1. 注释掉万能头

你**明确避免使用** `#include <bits/stdc++.h>`，而是将其注释掉：

```cpp
// #include <bits/stdc++.h>
```

### 2. 精确引入所需头文件

按需引入，并附带详细的中文注释说明用途：

```cpp
#include <iostream>  // cin, cout, cerr - 标准输入输出流
#include <cmath>     // sqrt, pow, sin, cos - 数学函数
#include <algorithm> // sort, min, max, reverse - 常用算法
#include <iomanip>   // setprecision, setw, fixed - 输入输出格式化
#include <string>    // string, getline - 字符串类
#include <vector>    // vector - 动态数组（向量）
#include <cstring>   // strcpy, strcmp, strlen - C风格字符串函数
#include <set>       // set, multiset - 集合
#include <map>       // map, multimap - 映射表（关联数组）
#include <tuple>     // tuple, make_tuple - 元组
#include <bitset>    // bitset - 位集
#include <utility>   // pair, make_pair - 对（序偶）
#include <queue>     // queue, priority_queue - 队列和优先队列
#include <deque>     // deque - 双端队列
#include <stack>     // stack - 栈
#include <numeric>   // gcd, lcm, accumulate - 数值算法
#include <climits>   // INT_MAX, LLONG_MAX - 整数最大最小值
```

### 3. 头文件引入顺序

通常按照以下顺序：
1. 输入输出流（iostream）
2. 数学库（cmath）
3. 算法库（algorithm）
4. 格式化（iomanip）
5. 字符串（string）
6. 容器（vector, set, map, queue 等）
7. 其他工具库（numeric, climits 等）

## 宏定义与类型别名

### 1. I/O 加速

**必备宏**，几乎每个文件都有：

```cpp
#define IOS ios::sync_with_stdio(0), cin.tie(0), cout.tie(0)
```

在 `main` 函数开头调用：`IOS;`

### 2. long long 宏定义

**强烈偏好**使用 `#define int long long`，避免溢出：

```cpp
#define int long long
```

配合使用 `signed main()` 而非 `int main()`。

**注意**：少数题目会注释掉此宏（当题目明确不需要 long long 或会导致 MLE）：

```cpp
// #define int long long
```

此时使用 `int main()` 或直接写 `signed main()`。

### 3. 换行符宏

使用 `\n` 代替 `endl` 提高效率：

```cpp
#define endl '\n'
```

### 4. 类型别名

```cpp
typedef pair<int, int> PII;
```

## 常量定义

### 1. 无穷大 INF

```cpp
const int INF = 0x3f3f3f3f;
```

当 `#define int long long` 未启用且需要 long long 时，单独定义：

```cpp
const int INF = INT_MAX;

```

### 2. 模数 MOD

```cpp
const int MOD = 1e9 + 7;
```

或根据题目：

```cpp
const int mod = 998244353;
```

### 3. 位运算操作注释

在常量定义区域附带位运算说明（几乎每个文件都有）：

```cpp
// &（按位与）: 只有当两个相应的位都为 1 时,结果位才为 1,否则为 0
// |（按位或）: 只要两个相应的位中有一个为 1,结果位就为 1,否则为 0
// ^（按位异或）: 如果两个相应的位不同(一个为 1，另一个为 0),则结果位为 1,如果相同则结果位为 0
```

## 常用工具函数

### 1. 快速幂

**标配函数**，几乎每个模板都有：

```cpp
// 快速幂
int fast_pow(int a, int b, int mod) // a ^ b % mod
{
    int res = 1 % mod;
    while (b)
    {
        if (b & 1)
        {
            res = res * 1ll * a % mod;
        }
        a = a * 1ll * a % mod;
        b >>= 1;
    }
    return res;
}
```

### 2. 最大公约数 gcd

**提供两种实现**，默认使用迭代版本：

#### 迭代（循环）实现

```cpp
// 手动实现 gcd
// 迭代（循环）实现
int gcd(int a, int b)
{
    while (b != 0)
    {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

#### 递归实现（通常注释掉）

```cpp
// // 手动实现 gcd
// // 递归实现
// int gcd(int a, int b)
// {
//     if (b == 0) return a;
//     return gcd(b, a % b);
// }
```

### 3. 最小公倍数 lcm

```cpp
// 手动实现 lcm
int lcm(int a, int b)
{
    if (a == 0 || b == 0)
        return 0;             // 避免除以零
    return a / gcd(a, b) * b; // 先除后乘防止溢出
}
```

### 4. 字符串转换注释

```cpp
// stoi/stoll: string数字 -> int/long long整数
// to_string: int/long long/float/double -> string字符串
```

### 5. 前缀/后缀缩写注释

```cpp
// pref 前缀（prefix）
// suff 后缀（suffix）
```

## 命名习惯

### 1. 变量命名

- **单字母变量**：`n, m, k, t, i, j, a, b, c`（循环变量和简单题目输入）
- **描述性变量**：`left, right, max_len, ans, num, temp`
- **数组/容器**：`arr, brr, mp, dp`
- **标志变量**：`flag, flat`（你倾向于使用 `flat` 表示布尔标志）

### 2. 函数命名

- **工具函数**：`fast_pow, gcd, lcm`（小写 + 下划线）
- **递归函数**：`dp`（简短命名，参数列表清晰）

### 3. 常量命名

- **全大写**：`INF, MOD, LLNF`

## 代码风格

### 1. 缩进与空格

- **4 个空格缩进**（非 Tab）
- 函数体、循环体、条件体统一缩进
- 大括号独占一行

### 2. 大括号风格

```cpp
if (condition)
{
    // code
}
else
{
    // code
}

while (t--)
{
    // code
}

for (int i = 0; i < n; i++)
{
    // code
}
```

### 3. 空行使用

- 函数之间空一行
- 逻辑块之间适当空行
- 变量定义与主要逻辑之间空行

### 4. 输出格式

使用三目运算符控制空格/换行：

```cpp
for (int i = 0; i < n; i++) {
    cout << char('A' + i) << (i == n - 1 ? endl : ' ');
}
```

或直接使用换行：

```cpp
if (flat) cout << "YES" << endl;
else cout << "NO" << endl;
```

### 5. 循环习惯

- **多组测试**：`while(t--)` 或 `while (t-- > 0)`
- **范围循环**：`for (auto c : s)` / `for (char c : s)`
- **索引循环**：`for (int i = 0; i < n; i++)`

## 注释习惯

### 1. 头文件注释

每个头文件后都附带**中文注释**说明用途：

```cpp
#include <iostream> // cin, cout, cerr - 标准输入输出流
#include <queue>    // queue, priority_queue - 队列和优先队列
```

### 2. 算法思路注释

复杂算法会添加详细的**中文思路注释**：

```cpp
// dp[mask][current_node][used_zero][used_double]
// mask: 二进制状态，表示走过的点
// current_node: 当前所在的点 (0 ~ n-1)
// used_zero: 0表示没用过重力加速，1表示用过
// used_double: 0表示没用过反重力加速，1表示用过
```

### 3. 关键步骤注释

```cpp
// 1. 普通跳跃 (不使用新技能)
dp[next_mask][v][z][d] = min(dp[next_mask][v][z][d],
                             dp[mask][u][z][d] + p[u][v]);

// 2. 使用重力加速 (变0)
if (z == 0) {
    dp[next_mask][v][1][d] = min(dp[next_mask][v][1][d], dp[mask][u][0][d] + 0);
}
```

### 4. 调试注释

保留调试代码但注释掉：

```cpp
// cout << "len = " << len << endl;
// cout << "first = " << first << endl;
// cout << "last = " << last << endl;
```

### 5. 特判说明

```cpp
// 特判长度1
if (len == 1) {
    if (first == '?') {
        cout << '2' << endl;
    }
    else {
        cout << '1' << endl;
    }
    continue;
}
```

## 总结

### 核心特点

1. **拒绝万能头**：明确引入所需头文件，附带中文注释
2. **long long 优先**：`#define int long long` + `signed main()`
3. **I/O 加速必备**：`IOS` 宏定义
4. **工具函数齐全**：快速幂、gcd、lcm 标配
5. **注释详细**：头文件注释、算法思路、关键步骤均有中文说明
6. **代码风格统一**：4 空格缩进，大括号独占一行
7. **命名直观**：`flag/flat`（布尔）、`arr/brr`（数组）、`mp`（map）
8. **位运算注释**：模板中固定附带位运算说明
9. **字符串转换注释**：`stoi/stoll` 和 `to_string` 用法说明
