# **【算法题】A：行列式求值**

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M
64bit IO Format: %lld

### 题目背景
模板题，无背景。

### 题目描述
给定一个 \(n\) 阶行列式 \(A\)，求 \(|A|\)。结果对 \(p\) 取模。

### 输入描述
第一行两个正整数 \(n\) 和 \(p\)。

接下来共 \(n\) 行，第 \(i+1\) 行 \(n\) 个正整数，其中第 \(j\) 个表示 \(A_{i,j}\)。

### 输出描述
输出 \(|A|\) 在模 \(p\) 意义下的最小自然数值。

### 示例1
- **输入**
```
2 998244353
1 4
1 5
```
- **输出**
```
1
```

### 数据范围
对于 \(100\%\) 的数据，\(1 \leq n \leq 600\)，\(1 \leq a_{i,j} < 10^9 + 7\)，\(1 \leq p \leq 10^9 + 7\)。

### 算法分析
使用高斯消元法求行列式的值。通过初等行变换将矩阵化为上三角矩阵，行列式的值等于主对角线元素的乘积（需要考虑行交换带来的符号变化）。
